# Paula Schmitt Articles Network

## Project overview
This repository hosts interactive network visualizations that map how Brazilian journalist Paula Schmitt interconnects her opinion pieces. Each article is represented as a node and edges highlight references and thematic relationships between the texts. The default experience is the second-generation interface (V2) served from `index.html`, while the original HTML-only graph is preserved as `index-v1.html` for archival access.

## Available visualizations
- `index.html` — Main visualization (V2) featuring topic filters, text search, metadata, exports, and a responsive layout built with modular JavaScript.
- `index-v1.html` — Legacy visualization (V1) that maintains the embedded dataset in HTML and the original experience used in the project's first versions.

## Tech stack
### Front-end
- **vis-network** (v9.1.2) renders interactive force-directed graphs.
- **Modern JavaScript (ES modules)** located in `assets/js/` to orchestrate data loading, filters, statistics, UI, and the network.
- **Custom CSS** (`assets/css/v2.css`) provides the responsive layout, controls, and accessibility improvements for V2.
- **Bootstrap 5** remains present in the V1 legacy visualization for the legend layout and original components.

### Data collection & automation
- **Python 3, BeautifulSoup 4, and Requests** power the scraper (`scripts/paula_schmitt_scraper.py`) which builds the canonical dataset.
- **GitHub Actions** (`.github/workflows/paula-schmitt-scraper.yml`) runs the scraper every Monday at 05:00 UTC (and on demand), committing changes to `data/paula-schmitt-network-v2.json` when new articles or relationships are found.

## Architecture

### V2 (index.html)
The featured interface is structured as a modular application:

```
index.html
assets/
  css/v2.css
  js/
    dataLoader.js      // fetches and normalizes the dataset and its colors
    graph.js           // encapsulates the vis-network configuration
    filters.js         // filter logic for topic, search, and period
    statistics.js      // counters and derived metrics
    ui.js              // DOM binding, events, and accessibility
    utils.js           // shared utilities (formatting, truncation, etc.)
data/
  paula-schmitt-network-v2.json  // canonical dataset generated by the scraper
```

`index.html` loads the stylesheet, initializes the modules, and requests the dataset via `fetch`. `GraphManager` applies the vis-network physics, `FiltersManager` controls filters and thematic focus, `StatisticsManager` derives counts, and `UIController` synchronizes the DOM, the legend, the metadata panel, and export actions.

### Legacy V1 (index-v1.html)
The legacy file maintains the original implementation on a single page with embedded node and edge arrays, neighborhood highlighting/filtering functions, and direct vis-network initialization. It remains functionally unchanged, except for the banner pointing to the main visualization.

## Key V2 features
- Topic filters with focus mode, quick select/clear, and search within the topic list.
- Text search and year range filter that can be combined with topic selections.
- Dynamic statistics for article counts, citations, distribution by topic, and publication timeline.
- Visualization of the author's most cited external sources as square nodes, with dedicated statistics and an information panel.
- Metadata panel with topic, publication dates, availability status, citation count, and a direct link to the article.
- Export of the filtered set in JSON and graph capture as PNG.
- Responsive layout with adaptive legend, scroll indicators for touch devices, and viewport-sensitive sizing.
- Exposure of dataset metadata (source, totals, generation timestamp) directly on the interface.
- Automatic weekly data updates via GitHub Actions workflow.

## Legacy V1 capabilities
The legacy visualization preserves:
- The static legend with colors associated with editorial topics.
- Neighborhood highlighting functions that dim unrelated nodes and restore labels around the selected article.
- Programmatic filtering utilities and handlers that open articles in new tabs.
- ForceAtlas2 configuration exposed through the vis-network settings panel.

## Dataset reference
The V2 dataset saved in `data/paula-schmitt-network-v2.json` follows this structure:

```json
{
  "metadata": {
    "generated_at": "2025-10-24T04:12:49Z",
    "source": "https://www.poder360.com.br/author/paula-schmitt/",
    "total_nodes": 298,
    "total_edges": 312,
    "total_articles": 214,
    "total_external_sources": 84,
    "min_external_citation_threshold": 2,
    "max_external_coverage_threshold": 0.8
  },
  "nodes": [
    {
      "id": "https://www.poder360.com.br/opiniao/exemplo/",
      "type": "article",
      "title": "Article Title",
      "url": "https://www.poder360.com.br/opiniao/exemplo/",
      "published_at": "2024-08-14T05:50:00-03:00",
      "listed_date": "2024-08-14",
      "theme": "Brazil",
      "available": true,
      "status_code": 200
    },
    {
      "id": "https://www.youtube.com/watch?v=example",
      "type": "external_source",
      "title": "Interview with XYZ",
      "domain": "youtube.com",
      "source_name": "YouTube",
      "citation_count": 5,
      "coverage": 0.18,
      "summary": "Frequent text used in citations: “Watch the full video”",
      "url": "https://www.youtube.com/watch?v=example"
    }
  ],
  "edges": [
    {
      "source": "https://www.poder360.com.br/opiniao/exemplo/",
      "target": "https://www.poder360.com.br/opiniao/outro-exemplo/"
    }
  ]
}
```

- Articles (`type: "article"`) preserve the classic fields for topic, dates, availability, and canonical URL.
- External sources (`type: "external_source"`) include the normalized domain, a friendly label (`source_name`), the number of articles citing them (`citation_count`), percentage coverage in the corpus (`coverage`), as well as `anchor_text` and the `cited_by` list with associated articles.

`assets/js/dataLoader.js` transforms the JSON into the structure expected by vis-network (including derived colors, truncated labels, and year extraction). The V1 legacy visualization continues to consume its own static arrays embedded in `index-v1.html`.

## Updating the dataset manually
1. Ensure Python 3.11+ and install the dependencies: `pip install -r requirements.txt`.
2. Run the scraper from the repository root: `python scripts/paula_schmitt_scraper.py --log-level INFO --min-external-citations 2 --max-external-coverage 0.8` (additional parameters are optional and allow adjusting external source filters).
3. Review the `data/paula-schmitt-network-v2.json` file, stage the changes, and create the commit.

The scheduled workflow will repeat the same steps every week and push automatically when differences are detected.

## Local development
- Since V2 fetches the dataset, serve the project on a static HTTP server (e.g., `python -m http.server 8000`) and open `http://localhost:8000/index.html` in a modern browser.
- The V1 legacy visualization can still be opened directly via the filesystem (`index-v1.html`) if necessary.
- There is no build step: both visualizations are static assets that can be hosted on GitHub Pages or any static file service.
